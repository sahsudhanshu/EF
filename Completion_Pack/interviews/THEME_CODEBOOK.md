# Theme codebook for interview notes

Code each interview against these themes (1 = clearly present, 0 = not mentioned). Add new themes if three or more interviews raise something not listed, and record the date added.

| Code | Theme | Look for |
|---|---|---|
| T1 | Scam exposure | Suspicious calls, messages, fake payment screenshots, fake customer-care numbers |
| T2 | Loss or near-loss | Actually lost money, or nearly did |
| T3 | Failed or stuck payment | Money debited but not received; slow refunds |
| T4 | Support friction | Hard to reach support, no human, slow resolution |
| T5 | Device-lock and security friction | Lock hard to use, shared phones, prompts that annoy or confuse |
| T6 | Trust cues | Brand, government backing, bank link, reviews, family advice |
| T7 | Reliance on family or peers | Asks children/relatives/shopkeeper for help |
| T8 | Language or literacy barrier | Hindi/regional language, reading difficulty, voice preference |
| T9 | Interest in a safety guide (concept test) | Would use; format and language preferences |
| T10 | Reservations about the guide | Distrust, fear it is a scam itself, no time |
| T11 | Institutional willingness to pilot (C only) | Would consider; decision owner; evidence required |
| T12 | Institutional budget signal (C only) | Any stated price range (record the number exactly; do not infer) |

Rules: code what the participant said, not what you infer. Use a short verbatim quote (under 25 words, anonymised) for each theme you want to cite. A theme appearing in one interview is an observation, not a pattern; do not call something a pattern unless at least 3 interviews mention it.
